# Use of AI in the slot 7 design

Designer: Christoph Maier. Slot 7 of Chipalooza #2 was a proof of concept of AI-assisted analog design: the designer specified and
directed the work, and AI coding agents (Claude, in Claude Code sessions, local and cloud) carried out much of the drawing, scripting,
simulation and documentation. This page states what the repositories show about that, and what a user of the block needs (no AI).
The records are cited by path only; their contents are not copied here.

## 1. What was AI-assisted

| kind of artifact | evidence of AI assistance (path, repository @ commit) |

## 2. Verification with open-source tools

All checks quoted for slot 7 were run with open-source tools. Versions recorded in `docs/replica_bias/RUNLOG.md` ("Tool versions", design
repository @ `9052bd35`): ngspice-47, xschem 3.4.8RC, CACE 2.11.0, KLayout 0.30.12, magic 8.3.685, netgen 1.5.324, Python 3.13.18,
PDK IHP-Open-PDK `ihp-sg13cmos5l` (`df4c5054`, 2026-10-14). The KLayout checks use the PDK's own decks (`run_drc.py`, `run_lvs.py`; see
`../README.md`); the reports are in [`../signoff/`](../signoff/README.md).

## 3. The designer's part

The designer specified the circuits and the modes, chose between alternatives and accepted results; the run logs record his decisions as
quoted instructions (for example RUNLOG rows 119, 121, 123, 125, 130: "release early", "go ahead with v3, then write the roadmap"). The
known LVS deviation of both pads on `vss` was "Accepted by Christoph on 2026-11-03" (`../README.md`). The repositories do not record a
line-by-line review of every generated file; what they record is the designer's direction and acceptance, and the checks above.

## 4. No AI needed to use, verify or modify the block

Everything a user needs is plain files: GDS layout, SPICE / CDL netlists, xschem sheets, Python and shell scripts, Markdown. Using the
block needs only these files; verifying it needs KLayout, magic, netgen, ngspice, xschem and CACE with the IHP open PDK; modifying it needs
the same tools. No step depends on an AI model or on any record of the AI sessions. What this repository does **not** yet contain to
reproduce every verification from here alone is listed in [RULES_COMPLIANCE_chipalooza2.md](RULES_COMPLIANCE_chipalooza2.md).
